Criação de Instâncias do Amazon EC2

Lab 171 - Provisionamento com Console da AWS, Instance Connect e AWS CLI

Neste laboratório, pratiquei o lançamento de um host bastion pelo Console da AWS, a conexão segura via EC2 Instance Connect, a automação de um servidor web utilizando AWS CLI e User Data, além da resolução de problemas de acesso e serviço em instâncias EC2.

Atividades realizadas

01

Host Bastion

Criação de instância t3.micro na Lab VPC com Security Group para SSH e associação do perfil IAM Bastion-Role.

02

Instance Connect

Conexão segura ao terminal Linux do host bastion pelo navegador para administrar recursos da conta AWS.

03

AWS CLI e User Data

Consulta de AMI no Parameter Store e lançamento automatizado de servidor web via linha de comando com script de inicialização.

04

Troubleshooting

Diagnóstico e correção de regras de acesso e do serviço Apache na instância Misconfigured Web Server.

O que aprendi

  • Criar e configurar instâncias Amazon EC2 pelo Console de Gerenciamento da AWS.
  • Associar uma IAM Role (Instance Profile) para autorizar comandos da AWS CLI sem armazenar chaves de acesso no servidor.
  • Conectar-se a instâncias Linux com segurança utilizando o EC2 Instance Connect.
  • Consultar parâmetros de AMI atualizados no Systems Manager Parameter Store via CLI.
  • Automatizar a criação e configuração de servidores web usando AWS CLI e scripts de User Data.
  • Diagnosticar e corrigir falhas de conectividade e serviços web em instâncias EC2.
